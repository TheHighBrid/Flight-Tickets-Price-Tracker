# FllightTicketsPriceTracker v2.00

This release packages the real-provider Flight Tickets Price Tracker as the installable Android v2.00 APK.

## Included

- Real Amadeus Flight Offers Search integration
- Provider carrier names, flight numbers, itinerary segments, schedules, stops, durations, baggage metadata, currencies, and total fares
- Saved target prices and provider-price history
- Approximately six-hour Android background checks when system and network conditions permit
- Notifications when a provider fare reaches a saved target
- Secure Android Keystore storage for private-device configuration
- Optional secure backend mode that keeps provider credentials outside the APK
- Test, lint, backend-test, smoke-test, APK-build, checksum, and release automation

## Configuration

The APK contains no embedded provider secret. Configure either a deployed HTTPS backend from the included `server/` directory or private-device Amadeus credentials inside the app.

Production live inventory requires Amadeus production credentials. The Amadeus test environment is clearly identified and provides limited test data.

## Integrity

The application has no generated-price fallback. Configuration, authentication, quota, connectivity, and provider errors are shown directly instead of being replaced with fabricated ticket prices.
