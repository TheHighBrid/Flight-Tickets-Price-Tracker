# FllightTicketsPriceTracker v2.01

This release removes the obsolete Amadeus setup experience from the installable build and ships the current free Google Flights provider integration.

## Provider changes

- Google Flights results are retrieved through SerpApi instead of Amadeus.
- SerpApi's free tier is sufficient for light personal use and does not require Amadeus production access.
- Direct-device mode uses one SerpApi API key stored with Android Keystore.
- Secure-backend mode remains available so provider credentials do not need to ship in distributed APKs.
- Old serialized Amadeus credentials are invalidated instead of being silently reused.
- No generated or simulated fare fallback is permitted.

## Why this release exists

The previously published v2.00 APK predates the provider migration, so its settings dialog still asks for an Amadeus environment, API key, and API secret. v2.01 rebuilds the app from the migrated code so the installed UI matches the current provider architecture.

## Verification

The release workflow runs backend tests, the live-model smoke test, Android unit tests, lint, and APK assembly before publishing the artifact and SHA-256 checksum.
